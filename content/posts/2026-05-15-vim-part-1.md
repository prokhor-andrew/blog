# Vim Part 1

## Basics   

Vim is a mode based editor. It has many different modes, but the main two ones are:
- Normal mode
- Insert mode

Other modes are:
- Command Line mode
- Search mode
- Replace mode
- Visual mode
- Visual Line mode
- Visual Block mode

We will get to them later.


Normal mode is the one where you enter other modes from.    
Insert mode is the plain text typing mode.

Normal mode allows you to execute some shorcuts by pressing diffent keys.
